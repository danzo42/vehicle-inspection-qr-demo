# 車両法定点検アプリ — デモ版

車両に貼ってあるQRシールをスマートフォンで読み取り、法定点検（3ヶ月／6ヶ月）を入力して、
紙と同じ書式の「定期点検整備記録簿」PDF（A4一枚）を作る PWA のデモ版です。

**このリポジトリは説明用のデモです。** 点検データはそのスマホの中だけに保存され、外部には送信しません。

## デモを開く

https://danzo42.github.io/vehicle-inspection-qr-demo/

スマホで開き「ホーム画面に追加」すると、アプリのように全画面で使えます。
初回だけオンラインで開けば、以後は電波が無くても動きます。

## 試せること

1. QRコードの読み取り（カメラ）、または管理番号の手入力で車両を特定
2. 点検入力（「レ 良好」をタップしていくだけ。省略できる項目は記録簿の下線・黄色の区別どおり）
3. 紙と同じ書式（会社ロゴ入り・A4一枚）の記録簿PDFを作成
4. 車載用コピーの印刷・共有（スマホの共有機能でプリンター・LINE・メールなどへ）
5. 点検履歴の確認、オフラインでの入力

## 本番について

本番では保存先を社内の環境（Azure／SharePoint）に差し替えます。
アプリは保存先を差し替えられる作りになっており、画面側の変更は不要です。
