# 点検QRポータル — デモ

車両の定期点検整備記録簿をスマートフォンで作成する PWA のデモ版です。

**このリポジトリは架空データによる動作デモ専用です。** 実在の車両情報は一切含まれていません。

## デモを開く

https://danzo42.github.io/vehicle-inspection-qr-demo/

## 収録データ

架空の車両8台のみ。車台番号は `SAMPLE-0000001` 形式のダミー値です。

| 管理番号 | 車種 | 点検区分 |
|---|---|---|
| DC2-0001 | 2t低床ダンプカー | 3ヶ月 |
| DC4-0002 | 4tエルゲートダンプカー | 3ヶ月 |
| UC4-0003 | 4tユニック | 3ヶ月 |
| K1BOX-0004 | 軽1BOX | 6ヶ月 |
| KTC-0005 | 軽トラック | 6ヶ月 |
| CAR-0006 | 乗用車（4WD） | 6ヶ月 |
| WS4-0007 | 4t散水車 | 3ヶ月 |
| SL12-0008 | 12mトラック式スカイマスター | 3ヶ月 |

## 試せること

- 管理番号のQRコード読み取りによる車両特定（カメラ）
- 管理番号の手入力による車両検索
- 3ヶ月点検45項目 / 6ヶ月点検21項目の入力
- 記録簿PDFの生成・共有・端末保存・印刷
- ホーム画面への追加（PWA）とオフライン動作

QRを試す場合は、上表の管理番号（例 `DC2-0001`）を任意のQR生成サービスでQR化して読み取らせてください。

## 動作要件

- **カメラ機能はHTTPS必須です。** `http://` や `file://` で開いた場合、QR読み取りは動作しません。上記のPages URLはHTTPSなので問題ありません。
- QR読み取りの対応ブラウザは iOS Safari / Android Chrome。

## 構成

外部CDNに依存しません。QR読み取り・PDF生成・画像化の各ライブラリはすべて `index.html` に埋め込み済みで、1ファイルで完結します（約0.9MB）。日本語Webフォントのみ Google Fonts から読み込みますが、未取得時は端末標準の日本語フォントにフォールバックします。
